Small project that shows two implementations of spawners using and not using the Factory pattern.
You can find the two scenes in the Scenes folder, and the scripts for the two implementations in the Scripts folder

The scripts are quite simple, so hopefully the comments there are enough to understand them :) 

There are two parts to this exercise: 
-the first part is more about thinking: take a look at the two scenes and the related scripts and try to write down the pros/cons to using the Factory pattern, compared with the implementation that doesn't use it
-the second part is more practical: in the folder for the Factory example there is another prefab "Sphere2". Try to make the PowerupFactory be able to create that too.
